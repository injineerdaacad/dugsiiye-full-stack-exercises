# Tailwind CSS Exercises

This repository contains a set of Tailwind CSS exercises organized to help you progressively learn how to use Tailwind utility classes effectively — from the basics to real-world UI components.

## 📘 Step-by-Step Exercises

Each folder focuses on a specific Tailwind concept. Go through them in order for best results:

- 📁 [tailwind-css-exercise-1](./tailwind-css-exercise-1/) – Flexbox
- 📁 [tailwind-css-exercise-2](./tailwind-css-exercise-2/) – Grid Basics
- 📁 [tailwind-css-exercise-3](./tailwind-css-exercise-3/) – Grid Rows
- 📁 [tailwind-css-exercise-4](./tailwind-css-exercise-4/) – Responsive Design
