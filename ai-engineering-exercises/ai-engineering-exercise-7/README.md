# Livestock Doctor 🐐

AI livestock health assistant for Somali herders — describe an animal's symptoms and get a
diagnosis, real treatment/medicine information, and (when urgent) the nearest vet contact.

## The problem

Somalia's economy runs on livestock (xoolaha), and most rural herders have no easy access to
a vet. A sick or dying animal can wipe out a family's income. This app gives a fast first
opinion grounded in real veterinary knowledge, not AI guesswork.

## Why RAG, not just "ask Gemini"

For animal health advice, wrong information is costly — a hallucinated disease or medicine
recommendation can harm the animal or waste money. Instead of letting Gemini answer freely,
this app retrieves matching entries from a curated knowledge base first, and the model is
instructed to answer **only** from what's retrieved.

- 22 real disease entries (camel, goat, sheep, cattle), each with cause, symptoms,
  transmission, real treatment/medicine, prevention, and urgency — CCPP, PPR, Anthrax, FMD,
  Trypanosomiasis, tick-borne fevers, Sheep/Goat Pox, Blackleg, Heartwater, and more
- Content is in `lib/data/diseases.json` — generated by asking Gemini directly for real,
  documented veterinary knowledge (not invented by hand), then reviewed and deduplicated
  before being committed as the fixed dataset the app grounds its answers in
- Embeddings (Gemini's `gemini-embedding-001`) are computed live via the API the first time
  the app needs them, then cached in memory for the life of the server — no database or seed
  step required for ~22 entries
- At query time, the herder's symptom description is embedded and compared against the
  cached vectors via cosine similarity (plain JS, no vector DB needed at this scale) — the
  top 3 matches become the grounding context for the model's answer

**Honest caveat**: medicine info includes real drug classes/treatment approaches, but not
precise per-kg dosing — that always depends on examining the actual animal, which is exactly
why urgent cases get routed to `findNearestVet`.

## Photos and language

- Herders can attach a photo of the animal instead of (or alongside) describing symptoms in
  text. The model describes what it visually observes (skin condition, swelling, discharge,
  wounds, posture) and folds that into the symptoms it hands to `diagnoseLivestock` — a photo
  alone is never treated as a diagnosis, it still goes through the same RAG grounding
- Replies match whatever language the herder writes in — Af-Soomaali, English, or a mix of
  both. Disease names stay in their standard recognized form (e.g. "CCPP (Contagious Caprine
  Pleuropneumonia)") even mid-Somali reply, since that's what herders and vets both use

## Tech stack

- Next.js (App Router) + TypeScript, no auth — a single-page chat tool
- Vercel `ai` SDK + `@ai-sdk/react` for the chat UI
- `@ai-sdk/google` (**not** the OpenAI-compat layer) for the Gemini chat model — this is
  required for reliable multi-step tool calling; Gemini's OpenAI-compat endpoint doesn't
  round-trip the `thought_signature` needed to replay tool calls, so multi-step calls 400
  through it
- Gemini's **native** REST endpoint for embeddings (`gemini-embedding-001`) — the
  OpenAI-compat layer doesn't support embeddings
- No database — `lib/data/diseases.json` and `lib/data/vets.json` are the whole data layer,
  loaded into memory at runtime

## ⚠️ Model name gotcha

`gemini-flash-latest` is a deprecated alias that returns sustained `503 UNAVAILABLE` ("high
demand") errors as of this writing. Use `gemini-3.6-flash` (set in `.env`/`.env.example`) —
confirmed working directly against the API before wiring it in.

## Setup — starting this project from scratch

Requirements: Node.js 18+ and a Gemini API key (free at
[aistudio.google.com/apikey](https://aistudio.google.com/apikey)).

```bash
# 1. Install dependencies
npm install

# 2. Add your Gemini API key
cp .env.example .env
# then open .env and set API_KEY=your-gemini-api-key

# 3. Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser — that's it, no database
and no seed step to run first. The first message you send will take a little longer than
usual (a few seconds) while the app embeds the knowledge base via the API; every message
after that is fast, since the embeddings stay cached in memory for as long as the server runs.

If port 3000 is already in use on your machine, start it on another port instead:
`npm run dev -- -p 3001` (then open `http://localhost:3001`).

## Tools

- `diagnoseLivestock({ animalType, symptoms })` — embeds the symptoms, retrieves the top 3
  matching disease documents, returns them as grounding for the model's explanation
- `findNearestVet({ region })` — looks up the vet/agrovet directory by Somali region

**Note**: the vet directory (`lib/data/vets.json`) is placeholder contact data for demo
purposes — swap in a real directory before using this with actual herders.

## Try it

- "My goat is coughing a lot and breathing really fast, seems weak" → correctly retrieves
  CCPP (Contagious Caprine Pleuropneumonia) as the top match
- "Riyahayga way qufacaysaa oo neefsashadu way ku adag tahay" (Af-Soomaali for the same
  symptoms) → same correct diagnosis, explained in Somali
- Attach a photo of a goat with facial scabs, no text needed → correctly identifies
  Contagious Ecthyma (Orf) from the visible lesions
- Follow up with a region name (e.g. "Banaadir") to get a real vet contact for urgent cases
