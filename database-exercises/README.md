# Database Exercises

This repository contains a set of hands-on database exercises designed to help you learn **SQL (MySQL)** and **NoSQL (MongoDB)** fundamentals — from basic CRUD operations to simple data modeling concepts.

---

## 📘 Step-by-Step Exercises

Each folder focuses on a specific database topic. Go through them in order to build a strong foundation before moving to full-stack development.
