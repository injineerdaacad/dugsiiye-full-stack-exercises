# Somali Intercity Transport System (SITS)

A full-stack web application for managing intercity transport bookings, routes, and payments.

## Features

- User authentication (Sign up, Login)
- Role-based access (Super Admin, Admin, User)
- City and Station management
- Route and Vehicle management
- Passenger and Cargo bookings
- Payment processing
- Profile management with avatar upload

## Tech Stack

- React + Vite
- Supabase (Auth, Database, Storage)
- TailwindCSS
- FontAwesome Icons

## Development

```bash
npm install
npm run dev
```
